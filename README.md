# ISMIR 2025 Conference Website

This repository serves [ismir2025.ismir.net](https://ismir2025.ismir.net) from its `gh-pages` branch.

The source code is maintained and released at **[joonhyungbae/ismir2025-website](https://github.com/joonhyungbae/ismir2025-website)** (MIT License), together with documentation on the site's architecture, how to adapt it for another conference, and a phase-by-phase timeline of what the site needed during the year. Start there if you want to reuse the code.

The `main` branch here holds an earlier snapshot of the source and is kept for reference.
